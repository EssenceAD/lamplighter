# 등불지기 (Lamplighter) 3.0

밤바다에서 올라오는 그림자들로부터 항구 마을을 지키는 종이 그림자극 길막기 디펜스. 세로 모바일, 지도 1개, 15웨이브.

- 플레이: https://essencead.github.io/lamplighter/
- 외부 소스: [SOURCES.md](SOURCES.md)

## 규칙 한눈에

- 그림자들이 바다(화면 아래) 두 곳에서 올라와, 가운데서 합쳐지는 굽은 길을 따라 마을(화면 위)로 갑니다. 한 마리가 들어가면 창문이 하나 꺼지고, 스무 개가 다 꺼지면 집니다(큰 고래는 한 번에 전부).
- 빛나는 자리 8곳을 누르면 원형 메뉴가 뜹니다. 탑을 한 번 누르면 설명과 사거리 원이 보이고, 한 번 더 누르면 세웁니다. 세운 탑을 누르면 올리기(3단계) · 특화(4단계, 둘 중 하나) · 팔기(쓴 값의 60%).
- 탑 4종: 횃불 궁수탑(빠른 화살, 날아다니는 적도 맞힘) / 등잔병 초소(등잔병 3명이 길을 막고 싸움, 모일 곳 지정) / 렌즈탑(느리고 센 빛, 껍데기 무시) / 봉화대(터지는 불덩이, 범위).
- 등대지기(영웅): 땅을 누르면 그리로 걸어가 근처 적과 싸웁니다. 쓰러지면 14초 뒤 등대에서 돌아옵니다. 초상화를 누르면 등불 휘두르기(주변 피해와 기절).
- 주문 2개: 섬광(누른 곳에 범위 피해) · 마을 지원군(누른 곳에 주민 2명이 잠시 길을 막음).
- 적: 잔챙이 / 빠른 날치 / 방패게(화살·불덩이에 강함) / 갈매기 그림자(날아서 초소가 못 막음, 궁수탑과 섬광만 닿음) / 거북(단단함) / 문어(쓰러지면 셋으로) / 큰 고래 그림자(15웨이브).
- 처치하면 바로 빛조각이 들어옵니다. 다음 웨이브는 16초 뒤 저절로 오고, 미리 부르면 남은 초만큼 보너스. 2배속 단추.
- 남은 창문 18개 이상이면 별 셋, 6개 이상 둘, 그 밖에 하나. 별로 영구 강화 5종(각 3단계)을 삽니다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/game.js` | 규칙 전부(순수 로직, node에서도 실행): 지도, 탑 4종, 등잔병·주민·등대지기, 적, 15웨이브, 주문, 검수용 봇 |
| `src/harbour.js` | 항구 무대(three.js). 적·아군은 종류별 인스턴싱, 체력바도 인스턴싱, 그림자 광원 1개, 밤 그림자 굽기, 해상도 자동 조절 |
| `src/app.js` | 화면·원형 메뉴·입력·루프 |
| `src/audio.js` | 배경음·효과음 합성 |
| `src/net.js` | 순위(Supabase `ll_` 함수) |
| `sw.js`, `manifest.webmanifest` | PWA, 새 버전 안내 띠 |

난이도 숫자는 모두 `src/game.js`에 손으로 적혀 있습니다(자동 보정 없음).

## 주소 옵션

- `?debug` 화면에 적 수 · fps · 해상도 배율 · 그리기 호출 수 표시
- `?mute` 소리 끔(테스트용)
- `?auto` 테스트용 임시 저장 사용

## 검수 도구

```bash
node tools/builds.mjs -v
```

영구 강화 없이 봇이 15웨이브를 돕니다. 합격 조건(설계에서 정한 것, 자동 보정 아님):

- 첫 웨이브: 아무 탑 2개를 아무 자리에 놓고 아무것도 안 해도 한 마리도 안 샘(20판)
- 무작위 탑 배치·무작위 올리기로도 클리어(20판 중 14판 이상)
- 탑을 섞고 잘 올리면 별 3개(6판 모두)
- 한 종류 탑만으로는, 영웅과 주문을 잘 써도 별 3개 불가(탑마다 5판)

깜빡임 검사: 브라우저 콘솔에서 `__ll.start({bot:'smart'})` 후 `__ll.flicker(30)` — 게임 시간 30초를 프레임 단위로 그리며 밝기를 읽어, 검은 프레임 수와 급변 프레임 수를 돌려줍니다.
`__ll.run(초)` 로 시간을 빨리 돌리고, `__ll.bench()` 로 현재 장면의 프레임 시간을 잽니다. 봇 종류: `smart`, `random`, `mono:archer` 등.

로컬 실행: `node tools/serve.js` 후 http://localhost:8123
