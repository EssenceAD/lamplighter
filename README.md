# 등불지기 (Lamplighter) 2.0.2

밤바다 절벽 위 등대 하나로 항구 마을을 지키는 종이 그림자극 디펜스. 세로 모바일, 지도 1개, 15웨이브 + 무한 모드(폭풍의 밤).

- 플레이: https://essencead.github.io/lamplighter/
- 외부 소스: [SOURCES.md](SOURCES.md)

## 규칙 한눈에

- 그림자들이 바다(화면 아래)에서 올라와 세 갈래 길로 마을(화면 위)까지 갑니다. 도달한 만큼 창문이 꺼지고, 다 꺼지면 집니다.
- 등대는 바다와 마을 사이 절벽 위에 서서 양쪽을 비춥니다. 빛줄기는 스스로 조준하고, 손가락으로 끌면 직접 조종합니다. 섬광은 등잔 단추로만 씁니다.
- 처치하면 빛조각이 들어옵니다. 받침대 자리 8곳을 눌러 원형 메뉴에서 세우고, 올리고(3단계 + 4단계 특화 택1), 돌리고(45도), 팝니다(70%).
- 거울·프리즘·렌즈는 **빛을 받아야** 켜집니다. 등대에서 가까운 자리는 등대 빛(가는 선)을 직접 받고, 나머지는 켜진 광학기의 빛줄기가 닿아야 합니다. 이어질수록(연결 단계) 위력이 커집니다.
- 종·봉화·반딧불 병은 빛 없이도 작동합니다.
- 웨이브 사이에 강화 카드 3장 중 1장(25종). 다음 웨이브를 미리 부르면 보너스 빛조각. 2배속 단추.
- 15웨이브를 넘기면 별을 얻고, 폭풍의 밤으로 이어갈 수 있습니다. 버틴 웨이브가 친구 순위에 올라갑니다.

## 구조

| 파일 | 내용 |
|---|---|
| `src/game.js` | 규칙 전부(순수 로직, node에서도 실행): 지도, 설치물, 빛 연결망, 적, 15웨이브, 카드, 경제, 검수용 봇 |
| `src/harbour.js` | 항구 무대(three.js). 적은 종류별 인스턴싱, 그림자 광원 1개, 밤 그림자 굽기, 해상도 자동 조절 |
| `src/app.js` | 화면·원형 메뉴·입력·루프 |
| `src/audio.js` | 배경음·효과음 합성 |
| `src/net.js` | 순위(Supabase `ll_` 함수) |
| `sw.js`, `manifest.webmanifest` | PWA, 새 버전 안내 띠 |

난이도 숫자는 모두 `src/game.js`에 손으로 적혀 있습니다(자동 보정 없음).

## 주소 옵션

- `?debug` 화면에 적 수 · fps · 해상도 배율 · 그리기 호출 수 표시
- `?mute` 소리 끔(테스트용)
- `?auto` 테스트용 임시 저장 사용

## 검수 도구

```bash
node tools/builds.mjs -v
```

서로 다른 빌드 4개를 봇으로 15웨이브까지 돌립니다(시드 3개씩). 합격 조건: 거울만 쓰는 빌드는 10웨이브 전에 패배, 광학기 없는 빌드 2종(봉화·병 중심 / 종·병 중심)은 15웨이브를 못 넘김, 빛을 잇는 조합 빌드만 클리어.

깜빡임 검사: 브라우저 콘솔에서 `__ll.start({bot:'combo'})` 후 `__ll.flicker(30)` — 게임 시간 30초를 프레임 단위로 그리며 GL 버퍼에서 밝기를 읽어, 검은 프레임 수와 앞 프레임 대비 급변 프레임 수를 돌려줍니다(중간에 해상도 변경·일시정지·카드 선택 포함).

브라우저 콘솔에서는 `__ll.start({bot:'combo'})` 후 `__ll.run(초)` 로 시간을 빨리 돌리고, `__ll.bench()` 로 현재 장면의 프레임 시간을 잽니다.

로컬 실행: `node tools/serve.js` 후 http://localhost:8123
