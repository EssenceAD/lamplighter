# 등불지기 (Lamplighter) 4.0

밤바다에서 올라오는 그림자들로부터 섬마을을 지키는, 접은 종이 모형 디펜스. 세로 모바일, 지도 1(등대 마을), 15웨이브, 난이도 3단계.

- 플레이: https://essencead.github.io/lamplighter/
- 설계 고정본: [DESIGN.md](DESIGN.md) — 모든 작업은 이 문서를 우선합니다.
- 외부 소스: [SOURCES.md](SOURCES.md)

## 규칙 한눈에

- 그림자들이 바다 쪽 입구 두 곳(화면 아래)에서 올라와, 가운데서 합쳐지는 긴 굽은 길을 따라 마을(화면 위)로 갑니다. 한 마리가 들어가면 창문이 하나 꺼지고(큰 고래는 열 개), 스무 개가 다 꺼지면 집니다.
- 설치 자리 11곳. 자리를 누르면 원형 메뉴가 뜹니다. 한 번 누르면 설명과 사거리 원, 한 번 더 누르면 세웁니다. 세운 탑: 올리기(3단계) · 특화(4단계, 둘 중 하나) · 특화 능력(1~2개, 능력마다 2~3단계) · 팔기(쓴 값의 60%).
- 탑 4종: 횃불 궁수탑(물리, 하늘도 맞힘) / 등잔병 초소(등잔병 3명이 길을 막음, 모일 곳 이동, 쓰러지면 다시 나옴) / 렌즈탑(마법, 껍데기를 뚫음) / 봉화대(물리, 범위).
- 방어 두 가지: 껍데기(물리 피해를 줄임)와 빛 막기(마법 피해를 줄임). 방패게·거북은 껍데기, 문어는 빛 막기.
- 등대지기(영웅): 땅을 누르면 그리로 가서 싸웁니다. 처치에 가까이 있으면 경험치를 얻어 6레벨까지 오릅니다. 쓰러지면 14초 뒤 등대에서 돌아옵니다. 초상화를 누르면 등불 휘두르기.
- 주문 2개: 섬광(누른 곳에 범위 피해·멈칫) · 마을 지원군(누른 곳에 주민 2명).
- 웨이브 깃발: 쉬는 동안 두 입구에 깃발이 서서 다음에 올 그림자를 보여 줍니다. 누르면 바로 시작하고, 남은 시간만큼 빛조각을 더 받습니다.
- 그림자를 누르면 정보 카드(이름·체력·방어·한 줄)가 뜨고, 처음 만난 그림자는 도감에 실립니다.
- 별: 남은 창문 18개 이상 ★3, 6개 이상 ★2, 그 밖에 ★1. 난이도(보통/숙련/폭풍)마다 최고 기록만큼 별이 모이고, 별로 탑 4종·주문 2종을 영구 강화합니다(돌려받기 가능).

## 파일

| 파일 | 하는 일 |
|---|---|
| `src/game.js` | 규칙 전부(지도·탑·특화 능력·적·웨이브·영웅·난이도·봇). DOM/three.js 없음, node에서도 돎 |
| `src/board.js` | 판 화면(three.js). 승인된 1단계 룩뎁의 장면 코드를 그대로 쓰고, 움직이지 않는 것은 재질별로 합침. 등롱 빛은 굽기(정점·빛 지도), 실시간 점광원 3개, 그림자 광원 1개(굽기) |
| `src/app.js` | 화면·입력·저장·루프 |
| `tools/builds.mjs` | 난이도 봇 검사 |
| `tools/artcheck.mjs` | 아트 검사 + 깜빡임 검사. 기준은 `tools/artref`의 승인된 룩뎁 그림 |

## 배포 전 검사

```bash
node tools/builds.mjs
```

```bash
node tools/artcheck.mjs
```

- `builds.mjs`: 첫 웨이브 무누수 / 보통에서 무작위 배치 20판 중 14판 이상 승리 / 좋은 조합 ★3 / 단일 탑 ★3 불가 / 숙련은 특화 없이는 패배 / 폭풍은 영웅·주문 없이는 패배.
- `artcheck.mjs`: 현재 게임 화면을 세 비율로 찍어 기준 그림과 나란히 저장(`tools/artcheck/compare.png`, `compare-all.png`)하고, 명도 폭·종이 결·그림자·따뜻한 빛 네 값을 비교합니다(85% 미만이면 실패). 같은 실행에서 깜빡임 검사(검은 프레임 0, 급변 0)도 합니다. 실패하면 배포하지 않습니다.
- `?debug`를 붙이면 fps·그리기 호출 수·해상도 배율이 보입니다. `?mute`는 소리 끔.
